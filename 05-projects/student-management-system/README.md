# Student Management System

This is my **first Java project**, built using the Java concepts I've learned so far. The project helped me practise these concepts by applying them to a simple, practical program.

## Features

1. **Student Details:** Displays student names, roll numbers, marks, and status in a tabular format.
2. **Pass/Fail Status:** Determines whether a student has passed or failed based on their marks.
3. **Average Marks:** Calculates the average marks of all students.
4. **Pass/Fail Count:** Counts the total number of students who passed and failed.
5. **Maximum Marks:** Finds the highest marks scored by a student.
6. **Topper Identification:** Displays the name of the student who scored the highest marks.

## Concepts Used

- Classes and Objects
- Instance and Static Variables

- Methods and Return Values
- Arrays of Objects
- Loops and Conditional Statements
- String Comparison using `equals()`
